# Accessible mini-games
Accessible mini games is a web-based project in React and JavaScript. It is made for the course "Digital Accessibility" at LTH and aims to to be accessible for people with visual impairments.
The goal is to create games, such as hangman, that can be played by people who use screen readers or have other visual impairments that require a certain type of interface. 

# How to start locally
Clone the reposotory 

    git clone https://github.com/emmahaggren/accessible-minigames.git

Change to the project folder 

    cd accessible-minigames

You will need npm, since this project is done in Vite.

    npm install

Then start the server

    npm dev run

Then open the localhost by pasting this url in your browser http://localhost:5173/hangman-game or by pressing o + enter in the terminal

All done, you can now enjoy the game!


OBS! If you face errors with missing react-router-dom or react-confetti please run

    install react-router-dom
    install react-confetti
